# 江湖行 — 武侠冒险

## Language

- Output language: zh (Chinese). Switch to en/ja anytime in-session.

## Premise & Worldbuilding

- 大梁王朝末年，江湖传闻失传百年的《天机残卷》重现于世，引得各大门派明争暗斗。你是一名初出茅庐的游侠，因偶然卷入一场灭门血案，被各方势力追杀，也一步步接近残卷背后的真相。

## Protagonist

- Identity: 初出茅庐的游侠，师承无名老丐
- Personality: 重情重义，嫉恶如仇，偶尔冲动
- Goal: 查明灭门血案真相，在各方势力夹缝中活下来

## Key Characters

- 林晚：青竹帮帮主之女，聪慧机敏，与你亦敌亦友；关系：青梅竹马
- 老陈：江湖百晓生，消息灵通，行踪诡秘；关系：你的引路人
- 沈孤鸿：朝廷鹰犬统领，武功高强，立场成谜；关系：追捕你的对手

## Core Rules

- Rule 1: 江湖重信义——背信弃义会降低所有角色的好感度。
- Rule 2: 内力与伤势是真实资源，受伤后战力下降，需休养或寻药。
- Rule 3: 每个选择都可能改变门派势力格局，影响后续剧情走向。

## Lorebook Entries (trigger keyword → setting content)

- 天机残卷：记载前朝秘术的残卷，传闻得之可号令天下
- 青竹帮：江南第一大帮，以竹为号，帮规森严
- 灭门血案：临安柳家一夜灭门，现场留有天机残卷的线索
- 朝廷鹰犬：大梁朝廷的密探组织，专查江湖异动

- 好感度：林晚=20，老陈=30，沈孤鸿=0
- 背包：破旧长剑、半块玉佩、一封无名信
- 特殊：已卷入血案=true，被通缉=true
